# 우아고라니 Discussion 운영 가이드

 ## 1. 목적

  매주 정기적으로 Discussion을 작성·공유하여, 팀원 간 학습 내용을 나누고 토론과 Q&A를 활성화한다.

 ## 2. 작성 주기

  - 매주 최소 1개의 Discussion을 등록한다.
  - 작성 주기는 1주 단위로 한다.

 ## 3. 정기 모임

  - 매주 월요일 오전 10시 30분에 모여, Up 버튼이 가장 많은 주제를 함께 이야기하는 시간을 가진다.
  - 월요일이 공휴일인 경우, 상황에 맞추어 별도로 일정을 조정한다.

 ## 4. Up 버튼 사용 기준

  - 해당 주제에 대해 함께 이야기를 나누고 싶을 때 Up 버튼을 누른다.
  - Up 수는 월요일 모임에서 다룰 주제를 선정하는 기준이 된다.

 ## 5. Discussion 작성 방법

  - 단순한 학습 정리보다는 토론·Q&A 형식의 내용을 권장한다.
  - 등록 시 카테고리를 확인하고, 그에 맞는 적절한 내용을 작성한다.

 ## 6. 템플릿 수정 요청

  - 템플릿에 추가하거나 보완하고 싶은 내용이 있으면 DM 또는 구두로 요청한다.
  - 요청된 내용은 검토 후 템플릿에 반영할 예정이다.
